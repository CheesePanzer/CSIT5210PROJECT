# Neural Network Reproduction

This directory src/network contains the neural-network reproduction code for the OVO/OVR imbalanced multi-class classification project.

## Requirements

The code was tested on Windows and Linux with Python 3.11, PyTorch, NumPy, pandas, SciPy, and scikit-learn. Create a virtual environment locally; do not commit the virtual environment or machine-specific paths.
Dependencies are provided at:

```text
src/network/requirements_pytorch.txt
```

Install dependencies from the project root:

```bash
python -m pip install -r src/network/requirements_pytorch.txt
```

## Main Files

```text
network_train_torch_manual.py   Main PyTorch training pipeline
paper_losses.py                 CE, OVR, and OVO loss functions
split_metadata.py               Split and dataset fingerprint metadata
tools/evaluate_predictions.py   Evaluate saved prediction CSV files
```

## Data

The training script expects the datasets under:

```text
data/raw/
```

You can use `--data-dir` to provide another local data directory. Do not commit local absolute paths or virtual environments.

## Running the Experiments

The two OVO implementations are maintained on separate branches:

| Branch | OVO variant |
|---|---|
| `feature/neural` | OVO-P: paper-formulation implementation |
| `feature/neural-author-code` | OVO-A: author-code implementation |

Switch branches before running the corresponding experiment:

```bash
git switch feature/neural or feature/neural-author-code
```

Run the full experiment:

```bash
python -m src.network.network_train_torch_manual --datasets ALL --device cuda
```

## Output

Each completed experiment produces:

```text
{dataset}_{loss}_{criterion}_folds12345_seed42.json
{dataset}_{loss}_{criterion}_folds12345_seed42_predictions.csv
```

The JSON file contains the configuration, training history, fold metrics, and combined test metrics. The prediction CSV contains sample_index, fold, y_true, y_pred

## Evaluate

The final paper-style result tables are generated by:

```text
src/network/evaluation script/build_final_results.py
```

Since the paper-formulation and author-code results are from different git branches.
They should be stored under one parent directory so that the script can detect them.

For example, with this layout:

```text
results/
├── paper_formula/
└── author_code/
```

run:

```powershell
python build_final_results.py `
  --paper-dir "results/paper_formula" `
  --author-dir "results/author_code" `
  --output-dir "results/neuralfinalresult"
```
